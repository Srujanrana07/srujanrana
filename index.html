VirtuEye - AI-Smart Glass for Visually Impaired People
VirtuEye is an innovative AI-powered smart glass designed to assist visually impaired individuals in navigating their environments safely and independently. The system employs a fine-tuned MobileNetV3 Convolutional Neural Network (CNN) for real-time object detection, integrated with YOLO (You Only Look Once) for immediate identification of obstacles. Optical Character Recognition (OCR) technology is utilized to extract text from images, providing users with vital information about their surroundings. Additionally, a natural language processing (NLP) model enhances user interaction by converting detected objects and text into meaningful audio descriptions. A comprehensive dataset was created and annotated using RoboFlow, ensuring high-quality data for improved model performance and accuracy.
